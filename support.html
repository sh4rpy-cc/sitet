Security & Integrity

Эвристика антивирусов (False Positive)

Утилиты системной модификации и плейбуки AME по умолчанию выполняют низкоуровневые операции: правка веток реестра, редактирование файла hosts, отключение системной телеметрии и завершение фоновых служб. Эвристические сканеры Windows Defender распознают такие действия как потенциально нежелательные. Исходный код открыт для аудита на GitHub.

# Проверка целостности бинарника в консоли PowerShell
Get-FileHash -Algorithm SHA256 .\FlibSystem.exe
