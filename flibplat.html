Execution Pipeline

Порядок развертывания

1. Запустите AME Wizard 0.8.x от имени Администратора.
2. Перетащите файл flibPlat.apbx в окно мастера.
3. Выберите компоненты для вырезания (Edge, OneDrive, Teams, Appx) и софт для оффлайн установки.
4. Запустите процесс. Система автоматически перезагрузится в оптимизированное состояние.

# Password-encrypted 7z format according to AME standard
powershell -ExecutionPolicy Bypass -File .\build.ps1
